# 外部评测：独立审查与修复

## 审查范围与初审结论

全部外部推理完成后，由独立、只读的 code-reviewer 上下文审查数据筛选、解码、评分、抽样区间、预测来源和交付限制。初审重新核对了 3,150 条预测、九组指标及九项差值区间；未发现使已完成结果失效的阻塞问题。

初审发现一项 P2 校验缺陷：旧读取器只检查 token 为整数，未检查词表范围，也未将保存的 `prediction` 文本绑定到 token 的实际解码结果。因此，单独修改文本或损坏 token 编号，有可能仍被评分器接受。

## 已实施的修复

- 从固定 Whisper-small 版本导出六个本地 tokenizer 文件，用资产哈希、模型版本和词表大小校验；拒绝缺失、损坏或未登记的影子资产。
- 读取预测时检查每个 token 编号的有效范围，并要求本地 tokenizer 解码与保存文本逐字一致。
- 相同读取检查供断点恢复和评分共用，损坏结果不能跳过检查继续追加。
- 词表大小在每次读取文件时只计算一次，避免在逐 token 循环里重复构造整个词表。
- 新增文本篡改、负数/超大 token、tokenizer 损坏/影子文件、历史身份白名单和历史部分结果禁止续写的回归检查。原管线与外部数据测试合计 **39 项通过**。

九个 `identity.json`、九个 `predictions.jsonl` 均保持原始字节。生成时的完整代码已逐字保存为 `provenance/external_eval_generation_v1.py`，SHA-256：

`06611afbb60ee79d0d7a366f1b17d73c7a42b6c822210b46e155bdbfc680d01e`

当前读取器仅额外允许这个已归档、哈希匹配的历史代码身份；配置、数据、参考、语言、权重和解码字段仍须完全匹配。完整历史结果只读复用；不完整的历史结果禁止混入新代码继续生成。新运行仍记录当前代码身份。
