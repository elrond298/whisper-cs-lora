# 外部子集验证计划：CS-Dialogue 与 FLEURS

状态：仅计划与数据源核查；尚未下载音频、运行模型或改变原训练产物。数据源事实与固定 revision 见 [EXTERNAL_EVAL_SOURCES.md](EXTERNAL_EVAL_SOURCES.md)。

## 1. 目的与固定条件

- CS-Dialogue：检验 ASCEND 内观察到的过采样收益能否延伸到另一套自然中英混合语音。
- FLEURS：检验 B/C 相对原模型 A 的通用中文、英文识别是否退化；C 相对 B 的差异是辅助判断，不能替代与 A 的比较。
- 不训练、不换 checkpoint、不调整 LoRA/学习率，不依据外部结果选择模型或调整解码。
- A 使用原固定版 Whisper-small，B/C 使用既有最终 800 步 adapter。保留原 ASCEND 配置、预测、报告和 checkpoint。
- 沿用确定性解码：beam=1、do_sample=False、max_new_tokens=256、禁用 forced_decoder_ids、既有 suppress/begin_suppress 设置；mixed/中文前缀 zh，英文前缀 en，task=transcribe。

## 2. 抽样协议（先冻结清单再推理）

固定 seed=42，限官方 test。ID 必须带数据集/语言/版本命名空间，FLEURS 录音 ID 使用唯一文件名，不误用可重复的句子 id。

| 数据 | 抽样目标 | 合格池与分层 |
|---|---:|---|
| CS-Dialogue | 上限 500 条 | 官方 <MIX> test 短句，优先覆盖可用的 30 位测试说话人并分散话题；不虚构不存在的对话 ID |
| FLEURS cmn_hans_cn | 300 条录音 | 普通话标签且规范化参考不含拉丁字母的中文单语转写子集；报告其筛选范围，不声称完整普通话测试集成绩 |
| FLEURS en_us | 300 条录音 | US-English test；尽量覆盖不同句子 ID，不将同句多次朗读视为独立文本 |

- 音频必须非空、有效且 <=30 秒。长样本不截断后对完整转写评分；本轮明确只评价短句范围。
- CS 使用已切分的 short_wav，不使用长对话 long_wav。按固定规则清除非口语标记；排除无法可靠评分的不可辨识标记 `**`，保留排除原因。
- 先按文本/索引建立候选序列；音频解码后再核实长度/损坏并按同一 seed 序列递补，不按模型表现挑样本。
- CS 最终 n=min(500, floor(合格 mixed 池大小/2))，确保始终只评测子集；不足目标时缩小并记录，不用 train/dev 补数。FLEURS 若不足目标也缩小且不全量评测；当前官方元数据表明目标规模可行，最终以全部筛选后的数量为准。
- 清单记录版本、文件名/ID、原始/计分参考、语言、时长、说话人/话题或句子 ID、筛选理由和音频哈希。检查来源及可行的 ASCEND 重合线索；不把外部来源直接等同于已证明无预训练污染。
- 所有模型严格复用同一清单。抽样分布、实际时长、独立说话人/句子数与排除统计均报告。

## 3. 数据获取与许可

- CS-Dialogue 元数据约8 MB；短音频 short_wav.tar.gz00–18 合计9,595,542,742 bytes。这些是分卷，尚未证明是独立可抽样的分片。先验证流式提取能否可靠取得固定子集；不能假设任意500条只需少量网络流量，保守预算是完整约9.6 GB短音频包。只保留所选音频，不下载约15.7 GB的 long_wav，不做全量推理。
- FLEURS 从 test TSV 先选择文件，再获取中英文 test 音频包，总计815,197,822 bytes；仅提取所选录音。不获取 train/dev、其它语言或整个102语言库。不升级/重装原冻结训练环境，也不依赖已被移除的远程加载脚本。
- 记录实际网络传输和落盘量，明确“评测条数”不等于“下载条数”。
- CS 卡片列有非商业/研究及额外转发限制。按研究用途与保守限制处理；音频/逐条参考只在本地研究目录使用，不自动并入可公开分发的交付包。若需先完成官方授权，则作为执行前置依赖，不因 API 公开而绕过。

## 4. 计分与判定

- CS：复用项目作者兼容 MER（中文字符+英文词），保留逐例编辑计数、空输出/重复/前缀/截断异常。标记处理在推理前冻结，不以评分结果决定清理规则。
- FLEURS：以官方 transcription 为参考，保留 raw_transcription；中文按字 CER，英文按词 WER。单语计分须独立验证，不能直接把 mixed 的 jieba 分词等同于标准英语词边界。统一规范化预测与参考，补缩写、连字符、数字等自检；不事后调整规则掩盖退化。不同数据集/口径不混成一个总分，原 ASCEND 报告口径不改。
- 每项报告 A/B/C 绝对分、B-A、C-A、C-B，差值单位为百分点，正值表示变差。
- 2000 次配对聚类 bootstrap：CS 按可验证的说话人分组，FLEURS 按句子 ID 分组，每次重算总编辑数/总参考单位数，不平均句级百分比。报告95%区间；CS 缺真实对话映射、FLEURS 缺说话人ID等相关性限制须注明。区间不覆盖训练随机种子不确定性。
- CS 的主要比较为 C-B：点估计<0 只叫方向性改善；区间上界<0 才说明当前固定模型在该子集有更明确的优势，仍不能推广为多种子策略稳定性。
- FLEURS 的主要比较为 B-A 与 C-A，预先采用中文+0.5pp、英文+0.8pp作为实用非劣界限（本项目规则，非官方阈值）。区间上界<=界限：支持未超过容忍退化；下界>界限：支持明显退化；跨界：证据不足。无论分类如何，都如实报告任何正的点估计，不把“未显著”写成“没有退化”。
- 不要求外部测试通过才能结束：不改善或单语退化也是有效结果，不调参反复测试直到通过。

## 5. 执行顺序、检查与交付

1. 固定源 revision、许可边界、计分规则与候选/最终抽样清单；核实音频获取、长度与转写。
2. 新增独立外部评测入口，复用现有模型加载和确定性解码；写入独立 data/artifacts/external_eval 命名空间，禁止覆盖原 A/B/C 输出。
3. 每个子集先用最终清单中的10条做加载/对齐/计分冒烟检查；修复实现问题，不据性能选模型/前缀。通过后继续余下样本，目标上限1100段、3300条A/B/C预测，而非全量评测。
4. 计算绝对/差分指标、置信区间、崩溃率和错误类型；保存可离线复算的逐例计数与身份绑定记录。CS 受限材料不公开分发。
5. 核验输入/预测ID完整且无重复、配置/adapter哈希一致、原54个实验产物未变；补抽样、音频-参考对齐、标准单语计分、身份保护和bootstrap的小型自检。
6. 输出 EXTERNAL_EVAL_REPORT.md、抽样/筛选记录、A/B/C预测与指标、配对差值区间及可复算说明，更新项目总体结论但不改写原ASCEND事实。先用10条冒烟测得速度，再报告实际剩余时间，不承诺未经测量的ETA。

完成标准：两个外部数据源的预定子集均实际完成A/B/C推理，产物可复算，准确区分“混合语音泛化”“相对原模型的单语退化”“证据不足”，并披露子集、下载、许可、相关性与单种子限制。
